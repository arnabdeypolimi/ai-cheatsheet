## Design Context

### Users
ML engineers, students and interview candidates who find the sheets through search. They print them on A4 or keep them open next to an editor while coding, so dense scanning matters more than first impressions.

### Brand Personality
Precise, dense, trustworthy. An expert's reference card: nothing decorative, every element earns its place.

### Aesthetic Direction
Field manual / engineering quick-reference card. Warm paper (oklch 0.968 0.013 85), near-black warm ink, hairline and dotted rules, numbered sections (01, 02 …), condensed uppercase headings.
- Type: Barlow Condensed (display), Barlow Semi Condensed (body), Red Hat Mono (inline code), STIX Two Text (math).
- Colour: one family, one accent per sheet at the same lightness and chroma (oklch 0.52 0.15 h): Lightning h=295, LLM h=180, NN h=255.
- Code blocks: VS Code Dark+ (#1e1e1e background, purple control keywords, blue def/class/self, yellow calls, teal types, orange strings, green comments).
- Anti-references: dark glow bands, pill chips, icon badges, side-stripe borders, gradient text, identical card grids, Inter/Roboto.

### Design Principles
1. Density over decoration: fit one landscape A4 page; never add elements that cost a line of content.
2. Structure through type and rules, not boxes: section numbers, weight and hairlines carry the hierarchy.
3. The accent is rare: section numbers, step numbers and small labels only.
4. Code should look like the IDE readers use, so they can transfer it to their editor at a glance.
5. Print-first: every colour must still read on a mono laser printer.
