About these cheat sheets

Each sheet fits on a single landscape A4 page, so you can print it or keep it open next to your editor. The code targets PyTorch 2.x, Lightning 2.x and current Hugging Face transformers, peft and trl.

Source files, issues and pull requests are on GitHub. Licensed CC BY 4.0, so you're free to share and adapt them with attribution.
